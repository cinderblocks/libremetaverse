# Test region archive

`ShoppingCenter.oar` is a region archive written by OpenSim 0.7.x in December 2012. It is used to check that
`OarFile` reads what OpenSim actually writes: 217 object files, 15 textures, a terrain and the region settings.

- Source: https://archive.org/details/oar-clutterfly-shopping-linda-kellie (file `ShoppingCenter.oar`)
- Author: Linda Kellie / Zadaroo, from the "Zadaroo OARs Collection"
- Licence: CC0 1.0 Universal (public domain dedication), as stated on the archive.org item
  (https://creativecommons.org/publicdomain/zero/1.0/)
- The file is unmodified.
